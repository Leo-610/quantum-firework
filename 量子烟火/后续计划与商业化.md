| 模块 | 状态 | 说明 |
|------|------|------|

## 二、产品愿景（12–24 个月）

**一句话**：北交大首个「空间化情感 × 烟火日常」双模态校园智能体；从 Demo 进化为**校内可运营的数字情感基础设施**。

**不做**：心理咨询替代品、食堂官方评价系统、通用 Chatbot。  
**要做**：低门槛情绪着陆 + 有空间记忆的校园文化表达 + 可对接学校官方服务的入口。

---

## 三、产品路线图

### 阶段 0 · 稳定运营（0–2 个月）— 竞赛后即时

**目标**：保证演示稳定、可传播、可维护。

| 事项 | 优先级 | 工作量 |
|------|--------|--------|
| 监控与告警（Vercel Analytics + `/api/health`） | P0 | 小 |
| Coze Bot 回复质量迭代（Prompt / 工作流） | P0 | 中 |
| 地标 POI 持续校准（坐标拾取工具） | P1 | 小 |
| 表世界「复制分享」生成带文案图片 | P1 | 中 |
| PWA 离线壳（manifest 已有，加 Service Worker） | P2 | 中 |
| 隐私政策 / 用户协议独立页面 | P1 | 小 |

**交付物**：稳定版 bjtu.app、分享卡片正常、答辩/路演可复现。

---

### 阶段 1 · 增强匿名体验（2–4 个月）

**目标**：不建账号库，先把「个人使用体验」做满，与现有隐私承诺一致。

- **IndexedDB 迁移**：替代 `localStorage` 存 plants，支持更长的情绪历史
- **导入 / 导出增强**：二维码备份、跨浏览器恢复
- **里世界**：情绪日历、地点统计、「本周最常去的情绪坐标」
- **表世界**：吐槽模板、雷达历史对比、食堂维度趋势（本机聚合）
- **地图**：按时间段回放个人 plants；可选「仅自己可见」热力层
- **无障碍**：键盘导航、屏幕阅读器优化、对比度模式

**原则**：数据默认不出设备；若上云需同步更新 `disclaimers.js` 文案。

---

### 阶段 2 · 账号与云同步（4–8 个月）

**目标**：跨设备同步、校内身份校验，为 B 端合作打基础。

#### 2.1 登录方案（北交大优先）

| 方案 | 优点 | 缺点 | 建议 |
|------|------|------|------|
| **学校统一认证（CAS/OAuth）** | 官方背书、天然限校内 | 需信息化中心对接 | ⭐ 首选 |
| 企业微信 / 微信扫码 | 传播快 | 需绑定学工号 | 备选 |
| `@bjtu.edu.cn` 邮箱验证码 | 实现快 | 非实时学籍校验 | 过渡方案 |
| 自建用户名密码 | 完全自控 | 安全与运维成本高 | 不推荐 |

#### 2.2 数据架构（建议）

```
浏览器 → Auth（JWT Session）→ Vercel API → Postgres（Neon / Vercel Postgres）
                                              ├── users
                                              ├── emotion_plants
                                              ├── user_settings
                                              └── audit_logs（敏感操作）
Coze user_id ← 稳定账号 ID（非随机 UUID）
```

**存储策略（里世界敏感）**：

- 默认：**plants 元数据上云**（坐标、类型、时间、摘要），**对话原文不上云或 7 天 TTL**
- 用户可「一键删除全部云端记录」
- 管理端仅看聚合统计，不看个体明文（除非法务/危机干预流程）

#### 2.3 功能清单

- [ ] 登录 / 登出 / 会话续期
- [ ] 首次登录：本机 `localStorage` 数据合并上传
- [ ] 跨设备同步 plants 与个人设置
- [ ] 可选：匿名模式（继续免登录使用，数据仅本地）

---

### 阶段 3 · 多用户与社区层（8–14 个月）

**目标**：在合规前提下，让「校园情绪地图」真正有「共鸣」而非「窥探」。

- **聚合热力图**：多用户 plants 匿名聚合（k-匿名 / 网格化，避免精确定位到个人）
- **时空回响 2.0**：仅展示经过脱敏的 AI 摘要，不含可识别信息
- **表世界榜单**：「本周最火食堂窗口」「最毒舌改写」（聚合 + 审核）
- **活动运营**：期末周主题、心理健康月、食堂新品节限定 Bot 皮肤
- **内容审核**：敏感词 + Coze 审核 Bot + 人工复核队列

**红线**：默认不公开个人情绪原文；不做人格画像对外展示；危机关键词触发心理中心引导（可记录触发次数，不记录原文）。

---

### 阶段 4 · 校内官方对接（14–24 个月）

**目标**：从「学生创意项目」升级为「学校认可的数字化服务入口之一」。

| 对接方 | 可能合作形态 |
|--------|----------------|
| 心理素质教育中心 | 预约系统深链、宣传栏二维码、危机干预转介流程 |
| 学工部 / 团委 | 心理健康月、新生季活动运营 |
| 后勤 / 餐饮中心 | 表世界吐槽 **聚合报告**（非个人投诉），辅助选品参考 |
| 信息化办公室 | 统一认证、域名 `*.bjtu.edu.cn`、等保咨询 |
| 图书馆 / 书院 | 地标故事扩展、阅读情绪主题 |

**交付形态**：管理后台（只读聚合 Dashboard）+ 年度数据报告 PDF + API 对接文档。

## 五、商业化建议

### 5.1 定位：ToSchool B2B2C，而非 ToC 订阅

量子烟火的核心资产是 **「高校场景 × 空间化情感 × 多 Bot 编排」**，最适合卖给 **学校 / 书院 / 心理中心 / 后勤**，由学校买单或联合运营，学生免费使用。

**不建议**早期对 C 端收订阅费（学生付费意愿低，且里世界涉及心理敏感，付费墙易引发舆论风险）。

---

### 5.2 可行商业模式（按落地难度排序）

#### 模式 A · 校内 SaaS 授权（⭐ 最推荐）

- **客户**：高校学工、心理中心、智慧校园项目组
- **产品**：白标「量子烟火」+ 本校地图 + 本校 Bot 知识库 + 管理后台
- **定价参考**：
  - 试点年费 **3–8 万 / 校**（单校区、≤2 万 MAU）
  - 标准版 **8–20 万 / 校 / 年**（含统一认证、聚合报表、运维）
  - 定制开发另计（对接教务/心理预约 API）
- **卖点**：比通用树洞更「有校园空间感」；比纯 Chatbot 更有「情绪可视化」；火山 / Coze 栈学校易接受

#### 模式 B · 活动运营与内容服务

- 心理健康月、新生季、食堂文化节 **主题皮肤 + 运营方案**
- 按次收费 **0.5–2 万 / 场**，或打包进 SaaS 年费
- 表世界产出 UGC 可反哺学校公众号 / 短视频矩阵

#### 模式 C · 数据洞察报告（聚合、脱敏）

- 向 **后勤餐饮** 提供：食堂维度情感倾向周报（非正式投诉系统）
- 向 **学工** 提供：校区压力热力时段（网格化匿名，用于资源调度参考）
- **必须**：法律审查 + 学校数据协议；绝不卖原始个体数据

#### 模式 D · 技术输出 / 联合品牌

- 与 **火山引擎 / 扣子** 共创「高校情感智能体」标杆案例
- Conference 演讲、白皮书、联合 PR → 带来线索而非直接收入
- 适合维持品牌影响力，配合火山杯后续资源

#### 模式 E · ToC 增值（谨慎、后期）

| 功能 | 可行性 | 说明 |
|------|--------|------|
| 高级 Bot 人格 / 皮肤 | 中 | 表世界娱乐向可行，里世界慎用 |
| 情绪报告 PDF 导出 | 中 | 个人纪念 / 复盘，非诊断报告 |
| 去广告 | 低 | 当前无广告，无需 |
| 实物周边（植物徽章等） | 低 | 文创，非主业 |

## 六、合规、风险与伦理

1. **里世界数据**：属敏感个人信息范畴；上云前必须过学校法务与心理中心共识。
2. **AI 幻觉**：持续强调「非心理咨询」；危机词库 → 心理中心电话 + 地图。
3. **表世界 UGC**：人身攻击、造谣、泄露隐私 → 审核 + 举报 + 封禁。
4. **未成年人 / 学籍**：若接统一认证，需遵循学校信息化管理规定。
5. **等保与备案**：校内正式部署可能要求 ICP + 等保二级；SaaS 化时需提前预算。

## 八、关键指标（North Star）

| 阶段 | 核心指标 |
|------|----------|
| 传播 | 分享卡片点击率、UV、次日留存 |
| 里世界 | 人均 plants 数、倾诉完成率、心理中心地图打开率 |
| 表世界 | 改写完成率、复制分享次数、雷达生成次数 |
| B 端 | 试点学校数、管理后台周活、学校续约率 |
| 安全 | 危机词触发 → 心理中心引导点击率（不含内容留存） |

**North Star Metric 建议**：**「每周完成一次情绪着陆（倾诉 + 植物落地）的独立用户数」** — 同时体现里世界价值与空间化差异。
