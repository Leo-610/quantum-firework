# 量子烟火 · 火山杯演示 PPT 详细大纲

> **版本**：v2.0 · 2026-06  
> **用途**：答辩现场 / 录屏片头片尾 / 团队分工制作  
> **建议页数**：**18 页主答辩** + 4 页附录（问答备用）  
> **演讲时长**：5 分钟（可压缩至 3 分钟：删页 2、5、14）  
> **体积限制**：总 PPT **≤20MB**（单图 ≤500KB，优先 WebP/压缩 PNG）  
> **在线体验**：https://bjtu.app  
> **二维码素材**：`public/bjtu-app-qrcode-share-card.png`

## 一、全局设计规范

### 1.1 画布与字体

| 项 | 规范 |
|----|------|
| 比例 | 16:9（1920×1080） |
| 主标题 | 32–40pt，粗体，左对齐或居中 |
| 正文 | 20–24pt，每页正文 **≤5 行** |
| 注释/来源 | 14–16pt，灰色 `#94a3b8` |
| 中文字体 | 思源黑体 / 苹方 / 微软雅黑 |
| 英文/数字 | Inter / SF Pro / Consolas（代码感） |

### 1.2 配色（与产品 VI 一致）

| 角色 | 色值 | 用途 |
|------|------|------|
| 深底 | `#0a0e1a` | 全局背景 |
| 里世界主色 | `#0ff0fc` | 量子、情绪、标题高亮 |
| 里世界辅色 | `#7b2fff` | 植物、回响、渐变 |
| 表世界主色 | `#ff6b35` | 烟火、食堂、雷达 |
| 表世界辅色 | `#f5a623` | 按钮、强调 |
| 正文 | `#e2e8f0` | 主文案 |
| 弱化 | `#64748b` | 副标题、注释 |

### 1.3 版式模板（建议 Master 4 种）

1. **封面页**：全屏背景图 + 居中标题 + 底部赛事/学校信息  
2. **内容页**：左上标题 + 右侧/下方大图（截图占 55–65%）  
3. **对比页**：左文字右表格，或左右双栏  
4. **收尾页**：大二维码居中 + slogan + 团队/致谢  

### 1.4 截图统一要求

- 浏览器：**Chrome**，地址栏可见 `bjtu.app`，隐藏书签栏  
- 分辨率：1920×1080 截屏后裁切  
- 里世界演示：选 **思源楼** 或 **图书馆**  
- 表世界演示：选 **学活食堂**，风格选 **鲁迅体** 或 **虎扑体**  
- Coze/Vercel 截图：**打码 Token、Bot ID、环境变量**
