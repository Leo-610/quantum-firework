# 量子烟火 · 火山杯录屏脚本

> **目标时长**：4 分 00 秒（符合 3–5 分钟要求，可剪至 3:30 或延长至 4:45）  
> **体积**：导出 1080p H.264，码率 6–8 Mbps，目标 **<50MB**  
> **录制环境**：https://bjtu.app（生产）或本地 `pnpm dev`（需 Coze 可用）  
> **浏览器**：Chrome 最新版，窗口 1920×1080，隐藏书签栏，缩放 100%

## 录制前准备

| 项 | 说明 |
|----|------|

| 鼠标 | 移动平滑，点击前短暂停顿 0.5s |

## 导出参数（<50MB）

| 参数 | 推荐值 |
|------|--------|
| 分辨率 | 1920×1080 |
| 帧率 | 30fps |
| 编码 | H.264 (.mp4) |
| 码率 | 6 Mbps → 4 分钟 ≈ 180MB  raw；**剪映/PR 导出时选「中等」或手动 5Mbps** → ~35MB |
| 音频 | AAC 128kbps 单声道旁白足够 |

**体积不够时**：  
- 去掉 2:25–2:35 风格快速滑动  
- 片头缩至 15s  
- 技术段仅字幕不插 PPT
